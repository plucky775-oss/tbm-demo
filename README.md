# Power TBM · BIXPO 시연

실제 앱 화면으로 설명하는 전시용 시연 앱입니다.

## 설명 순서
소개 → 안전회의 → 서명·회의록 → 안전가이드 → 현장도구·응급의료시설 → 안전 4컷(Safety 4-Cut) → 마무리

이전·다음으로 진행하며, 접어두는 발표 멘트, 화면 확대, 교육영상 전체 재생을 지원합니다. Safety 4-Cut은 파워TBM의 안전 4컷 기능으로 소개합니다.

발표 멘트 보기를 펼쳐 `멘트 수정`을 누르면 해당 페이지의 멘트와 진행 안내를 편집할 수 있습니다. `저장`한 내용은 같은 기기·브라우저의 localStorage에 페이지별로 유지됩니다. 다른 기기에는 동기화되지 않으며 브라우저 데이터를 삭제하면 없어집니다. `기본 멘트 불러오기` 후 저장하면 해당 페이지만 기본값으로 되돌립니다. `취소`는 저장된 내용을 바꾸지 않습니다.

## 실행
먼저 `node scripts/restore-video.cjs`로 원본 영상을 복원합니다.

`python3 -m http.server 8080 --directory public` 실행 후 http://localhost:8080 에 접속합니다.

## Vercel 배포
Framework Preset: Other / Build Command: `node scripts/restore-video.cjs` / Output Directory: public

처음 실행하면 예시 화면으로 시작합니다. 예시로 설명한 뒤 `전체 앱`을 누르면 오른쪽에 `https://power-tbm.vercel.app/`의 전체 운영 앱을 표시합니다. 기존 계정으로 로그인하며 입력·저장은 실제 앱에 반영됩니다. 시연 전용 exhibit 페이지는 더 이상 연결하지 않습니다.

발표의 이전·다음은 선택한 화면 모드를 유지하고, 처음으로는 첫 예시 화면으로 돌아갑니다. 실제 앱의 화면·입력·세션은 유지하며 전체 앱 / 예시 화면으로 전환할 수 있습니다. 영상과 마무리에서는 앱을 숨겼다가 돌아오면 같은 프레임을 다시 표시합니다.

앱의 로그인이나 외부 기능이 브라우저의 임베딩 제한으로 열리지 않으면 새 창에서 앱 열기를 사용합니다. 연결된 Safety 4-Cut의 로그인·새 창 동작은 원래 앱 설정을 따릅니다.

영상은 전송 한도 때문에 video-parts에 분할 저장되며, 배포 시 원본 바이트 그대로 복원하고 SHA-256을 확인합니다. 화질·길이·소리는 변경하지 않았습니다.

## 앱 로딩 및 검사
전체 앱은 `?presentation=1`로 열고, 앱 내용이 준비되었다는 응답을 받은 뒤 표시합니다. iframe의 load 이벤트만으로 성공 처리하지 않습니다. 15초 동안 응답이 없거나 앱 내용이 비면 재시도와 새 창 열기를 표시합니다. 재시도 버튼만 앱을 다시 불러오므로 저장하지 않은 입력이 있다면 새 창 열기를 먼저 사용하세요.

`frame-controller.js`는 연결 상태를, `live.js`는 미디어 표시를, `media.css`는 앱 영역 배치를 담당합니다. 준비 응답에는 상태와 요청 식별자만 포함하며 로그인 정보나 화면 내용은 전달하지 않습니다.

회귀 검사: `node --test tests/*.test.cjs` (추가 설치 없음). 임베딩 로그인은 브라우저 설정의 영향을 받을 수 있으므로 전시용 iPad에서 별도로 확인하세요.
